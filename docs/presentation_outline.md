# Đề cương 10–12 slide

Đây là kế hoạch nội dung, chưa phải file PowerPoint/PDF. Tổng trình bày gồm phần nói, demo 5–7 phút và vấn đáp theo thời gian học phần quy định.

| Slide | Nội dung | Minh chứng |
|---|---|---|
| 1 | Tên đề tài, lớp, hai thành viên | Tên và thông tin thật |
| 2 | Bài toán, câu hỏi nghiên cứu, phạm vi | Một ảnh 8×8 → nhãn 0–9 và xác suất |
| 3 | Dữ liệu, giấy phép, chất lượng | Nguồn UCI/scikit-learn, ảnh mẫu, số lượng |
| 4 | Split, leakage và preprocessing | Train/validation/test, seed 42, chia 16 |
| 5 | Baseline và MLP | LogisticRegression so với 1–2 lớp ẩn ReLU |
| 6 | Thiết kế bốn thí nghiệm | Cấu hình giới hạn, alpha/early stopping, chọn theo validation |
| 7 | Kết quả validation và test | Hai bảng riêng, metric thực tế |
| 8 | Learning curve và lỗi | Confusion matrix, cặp nhầm, ảnh lỗi |
| 9 | Web và API | Ba màn hình, input validation, Pipeline lưu sẵn |
| 10 | Demo trực tiếp | Theo `docs/demo.md` |
| 11 | Giới hạn, đạo đức, hướng cải thiện | Canvas ngoài miền, confidence, dữ liệu nhỏ |
| 12 | Kết luận, nguồn, đóng góp | Trả lời câu hỏi, link repo và đóng góp thật |

Có thể gộp slide 3–4 và 11–12 thành 10 slide nếu cần. Dùng hình/bảng thật từ artifact; không tạo số liệu để đẹp slide. Hai người cùng trình bày và cùng trả lời về dữ liệu/mô hình/API.
